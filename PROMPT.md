# The one prompt

The whole game in this repository was built from this single prompt, given once:

> Make a game where a cat rides a scooter through neon night traffic, dodging cars and grabbing gold coins.

That is the entire brief. Everything else — the lanes, the near-miss bonus, the coin
arcs, the speed ramp, the game-over screen — the agent decided and built itself.

- The game: `game.html` (one file, no engine, no dependencies — open it in a browser).
- The video of it being built and played: posted on X (its address goes in `POST.json`).
